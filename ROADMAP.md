# Churchill Roadmap

This document outlines the planned direction of Churchill.

The roadmap is not a promise. It is a guide. Churchill grows when new functionality is genuinely needed, not because of deadlines or release schedules.

---

# Current Stage

Churchill is currently in its foundation phase.

The project's architecture, design language, documentation, and development workflow are being established before significant user-facing functionality is introduced.

# Long-Term Vision

Churchill aims to become a lightweight, beautiful, and highly customisable Linux desktop experience that combines the openness of traditional Linux with the polish and approachability expected by modern users.

Development is intentionally slow. New features are added because they improve Churchill, not because they increase version numbers.

## Estimated Timeline

These milestones are goals rather than deadlines. Churchill is released when it is ready.

| Version | Target | Focus |
|---------|--------|-------|
| Foundation | July 2026 | Repository and project foundations |
| Framework | September 2026 | Documentation, architecture, development workflow |
| Structure | November 2026 | Theme engine and configuration system |
| Prototype | February 2027 | Core widgets and desktop components |
| Preview | June 2027 | Settings application and user experience |
| Alpha | Late 2027 | Feature-complete Alpha |
| Beta | Early 2028 | Public Beta |
| Stable - v1.0 | When Churchill is ready | Stable Release |

Stable is not the end of Churchill.

It is simply the point where the foundations are strong enough for others to build upon.

#### Churchill will never rush a release to satisfy a date.

Development should remain enjoyable. Features are added because they improve the system, not because they fill a release. Versions measure maturity, not time.
